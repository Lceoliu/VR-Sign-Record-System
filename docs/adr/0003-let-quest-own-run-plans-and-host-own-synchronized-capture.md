# Let Quest own Run Plans and Host own synchronized capture and archival

The Interaction Quest application creates and freezes the complete Run Plan when the Participant presses Start, including Run ID, Assistance Condition, task variants, passwords, signers, and exact Instruction Clips. The PC Host reports readiness, synchronizes Webcam Capture, receives experiment artifacts, and acknowledges durable storage, but does not randomize or mutate the Run Plan; Quest retains its local files until that acknowledgement. Interaction Runs and their artifacts use an Interaction-specific data contract instead of being represented as Recording Takes. This keeps the experiment executable without delegating gameplay authority to the network while accepting a small synchronization handshake and duplicate local/Host storage during transfer.

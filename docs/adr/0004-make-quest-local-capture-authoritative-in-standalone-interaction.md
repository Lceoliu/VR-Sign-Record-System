# Make Quest-local capture authoritative in Standalone Interaction

The Interaction application on this branch will run only in Standalone Study Mode. One application launch creates one pseudonymous Participant identifier shared by every Interaction Run in that Participant Session, while every Run still receives an independent Run ID. Quest creates the Run Plan, captures and seals the local artifact set, automatically preserves abandoned partial Runs as Aborted, and treats every sealed Completed or Aborted artifact set as final without upload, acknowledgement, or synthetic Host state. The Unity Interaction runtime therefore removes Host readiness, registration, heartbeat, upload, acknowledgement, and Webcam Capture paths; the separate `vr-sign-host` project remains in the repository for historical or other workflows but is not used by this application. This decision supersedes ADR 0003 for the Standalone Interaction branch and accepts later USB or ADB export and the absence of synchronized webcam video in exchange for eliminating network-dependent experiment failures.

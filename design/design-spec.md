# VR 手语录制台设计规范

设计基准图：`operator-console-concept.png`

## 视觉系统

- 画布：`#F4F5F2`，内容区：`#FFFFFF`，顶栏：`#1D2220`。
- 主文字：`#1B211F`，次文字：`#68716D`，边框：`#D6DAD7`。
- 已连接/开始：`#2F7563`；录制/结束：`#B6403C`；重录：`#B87A22`。
- 圆角统一 8px，使用 1px 边框；仅顶栏和固定操作条允许轻微阴影。
- 页面用分栏、分隔线和列表组织，不使用渐变、不堆叠悬浮卡片。
- 字体优先使用系统无衬线字体，数字计时使用等宽字体。

## 桌面布局

- 顶栏高 64px：产品名、服务状态、会话和句子进度。
- 左栏宽 268px：Quest 设备选择和外置相机选择。
- 中央弹性区域：当前句、外置相机画面、Quest 实时动作、Quest 场景画面、录制状态。
- 右栏宽 300px：句子队列和当前句 Take 文件。
- 底部操作条高 92px：开始、结束、重新录制和脚踏提示。
- 低于 1100px 时右栏移到主内容下方；低于 760px 时全部改为单列。

## 固定文案

- VR 手语录制台
- 本地服务在线
- 设备 / Quest 设备 / 重新扫描 / 外置相机
- 当前句子 / 外置相机 / Quest 实时动作 / Quest 场景画面 / 录制状态
- 句子队列 / 当前句 Take
- 开始录制 / 结束录制 / 重新录制
- 短按开始 / 结束，长按重新录制

动态信息（设备名、会话名、句子、Take、分辨率、帧率、计时）不得写死。
